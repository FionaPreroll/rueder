rueder

A self-hosted feed reader for a handful of people, in the spirit of Google Reader: one Rust server next to PostgreSQL, with a web page inside it and an Android app around that page. Feed reader apps such as NetNewsWire and Read You connect to it through the Google Reader API.

The source code on GitHub

Try it

  • Demo The reader with made-up feeds, in your browser. No server is behind it: what you change stays in this browser.
